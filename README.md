## Miniproject  (Sorting list with heterogenous (strings and integers) elements)
# Solution :

First Approach :
Convert datatype of each element in the list to string and then use sort() function.

Second Approach :
Use two empty lists.Check datatype of each element. If it is int then append element to first list otherwise append it to second list.Then use sort() on both lists and concatenate the lists obtained.
